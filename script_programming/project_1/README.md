The objective of this assignment was to build a fully responsive, static personal engineering portfolio website based entirely on 100% pure semantic HTML5 and modern CSS, serving as a clean foundation for integrating JavaScript logic in the subsequent laboratory.

---

## 🛠️ Tech Stack & Standards

- **Semantic HTML5:** Structured using dedicated sectional elements (`<nav>`, `<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) and a semantic contact form featuring native client-side validation.
- **Modern CSS:**
  - Design tokens architecture defined via Custom Properties in `:root`,
  - Modern two-dimensional and one-dimensional layouts (**CSS Grid** and **Flexbox**),
  - Fluid typography powered by `clamp()`,
  - Native **CSS Nesting**,
  - Centralized **Media Queries** ensuring full responsiveness across viewport widths from 360px up to 1920px.
- **Zero JS & Zero External Libraries:** Strict adherence to vanilla web standards without external frameworks (no Bootstrap, Tailwind, or CDN dependencies).
- **Accessibility & Security:**
  - Reverse tabnabbing protection on outbound links (`rel="noopener noreferrer"`),
  - Clear interactive accessibility states (`:hover`, `:focus-visible` for keyboard navigation).
